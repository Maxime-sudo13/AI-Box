Clés publiques de l'éditeur autorisées à signer les mises à jour (un fichier `.pub` par clé,
contenu : clé publique Ed25519 en base64). La clé privée correspondante ne doit jamais être
copiée sur un boîtier ni dans ce dépôt : elle reste hors ligne chez l'éditeur.

Créer la paire : `python -m app.ops editeur-cle ~/cle-editeur-business-ai-box.pem`
